Deine Session meldet sich — genau dann, wenn du trainieren willst.

Gib jeder Session ihren eigenen Rhythmus: alle zwei Tage um 15:00 oder jeden Montag, Mittwoch und Freitag. Zur gewählten Zeit kommt eine Push-Benachrichtigung aufs Handy — ein Tipp, und die Session startet.

  • event_repeat Alle paar Tage oder an festen Wochentagen
  • schedule Deine Uhrzeit, auch bei Zeitumstellung
  • notifications_active Push aufs Handy — ein Tipp startet die Session
